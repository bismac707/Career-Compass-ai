Career Intelligence & Skill Gap Analyzer

Career Compass AI is an interactive career guidance platform designed to help users explore potential career paths, evaluate their current skills, identify skill gaps, and create personalized learning roadmaps.

The platform transforms self-assessed skill information into actionable career development insights through interactive analytics and visualizations.

🚀 Key Features

- Career Path Explorer: Explore career opportunities across Data Science, Data Analytics, Business Intelligence, Machine Learning, Frontend Development and Product Analytics.
- Skill Assessment: Evaluate your current proficiency across relevant technical and professional skills.
- Career Readiness Score: View your estimated readiness for selected career paths.
- Skill Gap Analysis: Identify the skills that need improvement.
- Personalized Learning Roadmap: Get a structured learning plan based on identified skill gaps.
- Career Comparison: Compare different career paths and their skill requirements.
- Interactive Visualizations: Understand your skill profile through visual analytics.
- Share & Export: Share or print your career assessment report.

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js (where included)

📊 How It Works

1. Select a career path.
2. Complete the skill assessment.
3. Review your career readiness score.
4. Explore your skill gaps.
5. Follow the recommended learning roadmap.
6. Compare alternative career paths.

▶️ How to Run

No installation is required.

1. Clone or download this repository.
2. Open "index.html" in a modern web browser.
3. Complete the assessment and explore the results.

⚠️ Project Limitations

Career readiness scores and recommendations are indicative estimates based on the application's assessment rules. They are not predictions from a trained machine-learning model and should not be treated as guaranteed employment outcomes.
